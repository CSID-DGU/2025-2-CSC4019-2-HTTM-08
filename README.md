### K-Wave Server Repository

안녕하세요.
본 리포지토리는 생성형 AI를 활용한 K-Culture 뉴스 플랫폼, K-Wave의 서버(Server) 코드 저장소입니다.

기존에 팀 내부에서 관리하던 프로젝트 Organization이 별도로 존재하여,
그중 서버 리포지토리만 동국대학교 Organization으로 이전하였습니다.

아래 링크를 통해 K-Wave 프로젝트의 전체 리포지토리와 클라이언트 코드를 확인하실 수 있습니다.
